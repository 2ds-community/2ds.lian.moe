各服介绍

2d 服分为主服、副服和创造服，主服是生存服长期周目，副服是轮转周目，创造服是永久周目
主服使用 Prominence II RPG 整合包，主要玩法为线性 RPG 和大量的模组， 是一个综合性整合包，游戏内容覆盖科技、魔法、建筑、探索等等各个方面。本包的限制较少， 模组数量、种类众多，因此适合长期周目的服务器

邀请盗版玩家

2d 服的主服（即长期模组生存服）支持正版玩家邀请盗版玩家，我们会为盗版玩家注册一个离线账户来游玩。

正版玩家可直接联系群主，您只需告知壹粥粥粥您自己的正版 ID，以及所想要邀请的盗版玩家所要注册的 离线 ID 和 离线密码 即可。
如果壹粥粥没有及时回复，您也可以在群里询问，其他管理员如果有空可以帮您进行离线账户的注册！

注册好后，盗版玩家只需要使用所注册的离线 id 启动游戏，进入服务器后在聊天框输入 /l 密码 即可登录，例如 /l extremelysafepwd
