快速开始

只需引入三个 CSS 文件和两个 JS 文件，即可使用全部组件。零依赖，零构建，打开浏览器就能跑。

<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>我的页面</title> <!-- 1. 引入样式 --> <link rel="stylesheet" href="css/variables.css"> <link rel="stylesheet" href="css/base.css"> <link rel="stylesheet" href="css/components.css"> </head> <body> <!-- 你的内容 --> <!-- 2. 引入脚本 --> <script src="js/components.js"></script> <script src="js/app.js"></script> </body> </html>

文件结构

整个框架只有 5 个文件，职责清晰。

├── css/ │ ├── variables.css ← 设计令牌：颜色、字体、间距、圆角、阴影 │ ├── base.css ← 重置样式 + 排版 + 布局工具类 + 动画 │ └── components.css ← 所有 UI 组件样式 ├── js/ │ ├── components.js ← 可复用组件逻辑（Accordion、Toast、Reveal…） │ └── app.js ← 页面初始化 + 打字机效果 └── assets/fonts/ ← 本地字体文件

消息提示 Toast

右下角弹出的轻量提示，3 秒后自动消失。支持 JS 调用和 data-toast 声明式触发。

<!-- 方式一：声明式（data-toast 属性） --> <button class="btn" data-toast="提示内容">点击提示</button> <!-- 方式二：JS 调用 --> <script> ToastManager.show('消息内容'); // 默认 3 秒 ToastManager.show('消息内容', 5000); // 自定义时长（毫秒） </script>

滚动动画 Reveal

元素进入视口时淡入上移。基于 IntersectionObserver，只触发一次，性能友好。

滚动到这里时我会淡入出现
<!-- 给任意元素添加 .reveal 类即可 --> <div class="reveal"> 我会在滚动到视口时淡入 </div> <!-- CSS 原理 --> .reveal { opacity: 0; transform: translateY(24px); transition: 0.7s ease; } .reveal.visible { opacity: 1; transform: none; } <!-- JS 会自动通过 IntersectionObserver 添加 .visible -->

JavaScript

自动初始化

app.js 在 DOMContentLoaded 时自动调用以下初始化函数：

// app.js 自动执行： initReveal(); // 滚动动画 initSmoothNav(); // 锚点平滑滚动 initNavScroll(); // 导航栏滚动效果 initAccordion(el); // 所有 .accordion 容器 // data-toast 按钮自动绑定点击事件 // .typed 元素自动启动打字机

如果你只引入 components.js 而不引入 app.js，需要手动调用这些函数。

API 参考

函数参数说明
initAccordion(container) container: 包含 .accordion-item 的 DOM 元素 初始化手风琴交互，同组互斥
ToastManager.show(msg, duration?) msg: 字符串
duration: 毫秒，默认 3000		 在右下角弹出消息提示
initReveal(selector?) selector: CSS 选择器，默认 '.reveal' 为匹配元素注册滚动动画
initSmoothNav() 无 为所有 a[href^="#"] 添加平滑滚动
initNavScroll(selector?) selector: 导航栏选择器，默认 '.nav' 监听滚动，切换 .scrolled 类
